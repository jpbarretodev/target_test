# Desafios Técnicos

Opa, tudo bom?! Este é o meu repositório que usei para armazenar os códigos das resoluções dos 3 desafios propostos

Tentei deixar tudo o mais limpo, protegido contra bugs e respeitandos as regras de negócio.

## 📦 O que tem por aqui?

*   **Desafio 1:** Cálculo  de comissão baseado nas faixas de valor, acumulando o total por vendedor e salvando o relatório atualizado em um novo JSON.
*   **Desafio 2:** Sistema de entrada e saída de produtos no depósito, com validação para o usuário não negativar o estoque e uso de UUID para rastreamento exclusivo, tipo um hash igual ao git.
*   **Desafio 3:** Cálculo de juros diários que atenta se o usuário tentar colocar uma data futura ou formato inválido.

Desde já, agradeço pelo tempo dedicado a avaliar meu teste!
